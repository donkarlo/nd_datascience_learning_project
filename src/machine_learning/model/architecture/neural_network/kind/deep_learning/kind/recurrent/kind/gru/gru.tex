   \maketitle

   \cite{cho-2014-learning-phrase-representations-using-rnn-encoder-decoder-for-statistical-machine-translation} introduce an RNN Encoder--Decoder architecture for learning representations of variable-length sequences .
   The paper proposes a new recurrent hidden unit inspired by LSTM but with a simpler gating structure. The unit uses a reset gate to control how much previous information is ignored and an update gate to control how much previous state is retained. These gates allow different hidden units to capture dependencies at different temporal scales. This gated recurrent architecture later became widely known as the Gated Recurrent Unit (GRU).
