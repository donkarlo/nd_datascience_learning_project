\section{Scoring rule}
Let \(Q_1\) and \(Q_3\) be the first and third quartiles of a reference sample. The interquartile range is \(\mathrm{IQR}=Q_3-Q_1\). Tukey's rule flags values below \(Q_1-1.5\,\mathrm{IQR}\) or above \(Q_3+1.5\,\mathrm{IQR}\).

\section{Example}
If the quartiles of daily processing times are \(12\) and \(20\) seconds, the fences are \(0\) and \(32\) seconds. A time of \(37\) seconds is flagged.

\section{Practical considerations}
Use comparable observations to estimate the fences. A long right tail can generate many flags even under normal operation. When the IQR is zero, the fences collapse, so inspect ties and use an explicit tolerance if small deviations are expected.
