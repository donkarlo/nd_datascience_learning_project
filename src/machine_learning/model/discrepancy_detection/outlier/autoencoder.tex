\section{Scoring rule}
An autoencoder learns an encoder \(f_\theta\) and a decoder \(g_\phi\) on representative reference data. With \(p\) numeric features and reconstruction \(\hat x=g_\phi(f_\theta(x))\), one possible score is
\[
s(x)=\frac{1}{p}\sum_{j=1}^{p}(x_j-\hat x_j)^2.
\]
Large errors indicate that the learned representation reconstructs an observation poorly.

\section{Example}
Train on standardized feature vectors from routine machine operation. If a new vector combines an ordinary temperature with a vibration pattern rarely seen at that temperature, the reconstruction may fit the routine pattern and leave a large vibration residual.

\section{Practical considerations}
Fit preprocessing on training data and calibrate the threshold on held-out data. For example, a high validation quantile estimates a reference false-alarm rate if deployment data remain comparable. Excess model capacity or contaminated training data can let the model reconstruct unusual inputs well. Inspect per-feature errors when investigating flagged points.
