\section{Clustering rule}
DBSCAN counts neighbors within a radius \(\varepsilon\). A point is a core point if its neighborhood contains at least \(\mathrm{MinPts}\) observations, including itself. Connected core points form clusters, and nearby non-core points can join as border points. Points left unassigned are labeled noise.

\section{Example}
For one-dimensional measurements \(10.0,10.1,10.2,10.3,15.0\), choosing \(\varepsilon=0.25\) and \(\mathrm{MinPts}=3\) groups the four nearby values and labels \(15.0\) as noise.

\section{Practical considerations}
Scale features and choose a metric that reflects similarity. A single radius can fragment sparse groups or merge nearby dense groups. Treat noise labels as candidates for review. A small, tight group of abnormal observations can still form a cluster.
